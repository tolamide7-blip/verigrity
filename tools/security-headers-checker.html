Security Headers Checker

Inspect the HTTP security headers a website sends and which browser protections are in place.

Headers checked

  • Strict-Transport-Security (HSTS)
  • Content-Security-Policy (CSP)
  • X-Content-Type-Options
  • X-Frame-Options
  • Referrer-Policy
  • Permissions-Policy

Limitations

This tool reports observable signals only. It is not a security audit, a business verification, or proof of fraud. Always verify independently.
